# SAMPLE 1010 L01: Course introduction and computational foundations

> [!SUMMARY] Summary
> Opening lecture for SAMPLE 1010. Introduces the course structure, grading breakdown, and academic integrity policies. Discusses the layered architecture of computer systems, moving from physical silicon up through instruction set architectures, operating systems, and high-level application software. Formalizes the concept of abstraction and introduces the von Neumann computer model.

---

## Key learning objectives

1. Understand the six layers of modern computer systems.
2. Define [[Sample-Core-Concept]] and explain its role in system design.
3. Trace how machine instructions move between main memory and the CPU register bank.

---

## In-depth lecture takeaways

### 1. The abstraction stack

```
+-------------------------------------------------------------+
| Applications (Web, Games, Mobile Apps)                     |
+-------------------------------------------------------------+
| Operating System & Libraries (Memory, Processes, Files)      |
+-------------------------------------------------------------+
| Instruction Set Architecture (x86, ARM, RISC-V)             |
+-------------------------------------------------------------+
| Microarchitecture (Pipelining, Branch Predictors, Caches)   |
+-------------------------------------------------------------+
| Digital Logic (Gates, Multiplexers, Flip-Flops)             |
+-------------------------------------------------------------+
| Physical Hardware (Transistors, Silicon, Interconnects)     |
+-------------------------------------------------------------+
```

Each layer provides a standardized interface to the layer above it, shielding programmers from lower-level physical mechanics.

---

### 2. Core principles of system design

- **Abstraction**: Isolating interface from implementation. See [[Sample-Core-Concept]].
- **Modularity**: Dividing complex architectures into testable, replaceable units.
- **Trade-offs**: Balancing throughput, latency, power consumption, and manufacturing cost.
