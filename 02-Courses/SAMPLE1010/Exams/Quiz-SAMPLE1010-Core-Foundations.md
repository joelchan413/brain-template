# Quiz: SAMPLE 1010 core foundations

```
What is the core principle of abstraction in computer systems?
?
Abstraction hides underlying physical implementation complexity (circuits, registers, machine code) behind clean interfaces (APIs, system calls, high-level languages), allowing engineers to reason about complex systems without tracking low-level hardware details.

```

```
What is the difference between a program and a process?
?
A program is passive code stored on disk. A process is an active instance of that program running in memory with an allocated address space, CPU registers, and execution state.
<!--ID: 1725169999002-->
```
